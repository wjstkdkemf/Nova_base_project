# Nova_base_project: Unity 기반 비주얼 노벨 제작 시스템

## 프로젝트 소개

본 프로젝트는 비주얼 노벨(Visual Novel) 제작 툴을 참고하여 Unity 엔진 환경에서 텍스트 및 이미지 렌더링, 미니게임 시스템을 직접 설계하고 구현한 것입니다. JSON 파싱을 활용한 유연한 대화 시스템, Lua 스크립트를 이용한 확장성 있는 캐릭터 이미지 생성, 그리고 효율적인 미니게임 관리 시스템 구축에 초점을 맞추었습니다.

## 주요 기능 및 구현 시스템

* **대화 시스템**
    * JSON 기반 파서를 활용하여 메모장으로 작성된 대사 내용을 UI에 파싱하여 출력.
    * 대사뿐만 아니라 원하는 특수 효과(예: 화면 흔들림, 페이드 인/아웃)를 중간에 삽입하여 대사와 특수 효과를 구분하여 처리.

* **Lua 기반 동적 캐릭터 시스템**
    * Lua 스크립트를 활용하여 머리, 눈, 옷 등 파츠(Parts)를 조합하여 하나의 옵션으로 생성.
    * 미리 정의된 파츠 조합을 `Dictionary` 형태로 저장하고, 파싱된 텍스트의 Key 값에 따라 해당하는 이미지를 동적으로 로드하여 높은 확장성 확보. (새로운 파츠나 조합 추가 용이)
    * Code : [CharacterSystem.cs - Line 42 (Link)]

* **미니게임 모듈화**
    * `ViewController`를 활용하여 미니게임 컨트롤러를 설계하고, 각 미니게임을 프리팹(Prefab) 단위로 제작 및 로딩.
    * 미니게임 로더를 통해 필요한 미니게임을 동적으로 생성 및 해체하여 리소스 관리에 용이하도록 구현.
    * Code : [MiniGameLoader.cs - Line 25 (Link)]
 
* **기존 엔진 분석 및 구조 개선**
    * 기존 Nova 엔진의 복잡한 상속 구조를 분석하여, 프로젝트에 불필요한 기능을 덜어내고 경량화했습니다.
    * 디버깅을 통해 코어 로직 흐름을 파악하고, `GameManager` 중심의 스파게티 코드를 기능별 매니저(`DialogueManager`, `ResourceManager`)로 분리했습니다.
